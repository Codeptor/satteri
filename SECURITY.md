# Security policy

## Reporting a vulnerability

Report security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Codeptor/satteri/security/advisories/new).
Include the affected revision, impact, reproduction steps, and any suggested
mitigation.

Do not file a public issue for a vulnerability or include sensitive details,
credentials, private data, or exploit material in public discussions.

## Project boundary

Satteri is paper-only software and has no real-money execution path. It does
not accept wallets, deposits, private keys, signers, exchange actions, or live
orders. A report showing that this boundary can be bypassed is security
relevant even if no funds are currently at risk.

The project is under active construction. Report vulnerabilities against the
current default branch and identify the exact commit tested.
